# Қаныш және ғылыми майдан — онлайн оқырман

Оқырманға берілген PDF-тен 454 бет бойынша мәтін енгізілді: `text/001.txt`–`text/454.txt`. PDF-тегі алғашқы үш бет бос; қалған 451 беттен мәтіндік қабаты алынды. Негізгі оқу режимі — бет нөмірлері бар терілген кітап мәтіні; сканды «Скан» батырмасымен көруге болады. PDF-тің өзі сайтқа көшірілмеген.

## Кітап беттерін қосу

PDF беттері 454 болғандықтан, `config.js` ішіндегі `pageCount` мәні 454. Кітаптың баспа дерегінде көлемі 456 бет деп көрсетілген.

Қазір PDF беттерімен сәйкестігі тексерілген екі скан бар: `pages/009.jpg` — 7-бет, `pages/892.jpg` — 354-бет. Басқа PDF беттерінің скандары әлі қосылмаған; оларды `pages/` ішіне `001.jpg`, `002.jpg`, `003.jpg` пішімімен енгізуге болады. Файл атауы PDF бетінен өзгеше болса, `config.js` ішіндегі `scanPages` сәйкестік кестесіне қосыңыз. WebP қолдансаңыз, `pageFormat` мәнін `"webp"` деп өзгертіңіз.

Мәтін файлдары UTF-8 форматында, PDF-тегі бет нөмірлерімен сақталған. Оқу кезінде «Аа» батырмасы ағымдағы беттің мәтіндік нұсқасын ашады; мәтін бұрын жүктелсе, офлайн режимде де қолжетімді болады.

Бөлімдерді `toc.json` файлына мына пішімде енгізіңіз:

```json
{
  "chapters": [
    { "title": "Бөлім атауы", "page": 1 }
  ]
}
```

`config.js` файлына автор мен қысқаша сипаттаманы да енгізуге болады.

Кітаптың мәтіні мен скандарын ашық жарияламас бұрын оларды тарату құқығы барын тексеріңіз.

## Жариялау

GitHub Pages не Netlify-та жариялау бумасы ретінде `reader-site/` таңдаңыз. Service worker офлайн режимде тек бұрын ашылып жүктелген беттерді сақтайды. PWA орнату және service worker функциялары үшін сайтты HTTPS арқылы ашыңыз; `file://` режимі тек қарапайым алдын ала қарауға арналған.
